# Frontend backend contract

The current source of truth is [FRONTEND_BACKEND_CONTRACT_V2.md](./FRONTEND_BACKEND_CONTRACT_V2.md).
Read that document in full, including the relevant DTOs and remaining limitations,
when implementing or updating a frontend feature.

`FRONTEND_BACKEND_CONTRACT_V1.md` is retained as a historical snapshot. Its missing
auth, bot, and run endpoints and old DTO naming do not describe the current API.
This entry point keeps the established project/skill path stable without maintaining
a second copy of the live contract.
